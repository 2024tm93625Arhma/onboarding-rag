# How to Install Software from the Catalogue

The self-service software catalogue lets you install approved applications
on your company laptop without raising a ticket. This page explains how to
use it. Which software is allowed, how to request software that is not in the
catalogue, and how long IT takes to fulfil a request are all covered by the
Software Installation Policy.

## Opening the catalogue
- **Windows:** open the Start menu and search for *Software Centre*.
- **macOS:** open *Self Service* from the Applications folder.

Sign in with single sign-on if asked.

## Installing an application
1. Search for the application by name, or browse by category.
2. Select it and read the short description.
3. Click *Install*. Installation happens in the background, and you can keep
   working.
4. Some applications need a restart. The catalogue will tell you, and you can
   choose when to restart.

## Updates
The catalogue updates installed applications automatically. You may see a
notice asking you to close an application so that it can update.

## Removing an application
Open the catalogue, go to *Installed*, select the application and click
*Uninstall*.

## Something is not in the catalogue
Search again with a different name, since some tools are listed under the
vendor name. If it is still not there, raise a software request through the
IT service portal as described in the Software Installation Policy.

## Installation fails
Restart the laptop, make sure it is connected to the network and try again.
If it fails again, raise a ticket in the IT service portal and include the
error code shown in the catalogue.
