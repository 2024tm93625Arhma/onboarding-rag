# Software Installation Policy (v2)

## Purpose
This policy explains how employees get software installed on company devices
and which software is allowed.
It replaces v1 for all employees.

## Self-service catalogue
Commonly used software is available in the self-service software catalogue on
every company laptop. Anything in the catalogue can be installed at any time
without a request or approval.

## Requesting other software
Software that is not in the catalogue must be requested through the IT service
portal. The request must state the software name, the version, the business
reason and whether a paid licence is needed. The employee's manager approves
the request, and IT Security reviews any software that has not been assessed
before.

## Fulfilment time
Once a request has been approved, IT installs the software or adds it to the
catalogue within **3 business days**. Requests that need a new paid licence
may take longer if procurement is required; the employee is told the expected
date when the request is approved.

## Prohibited software
The following must never be installed: peer-to-peer file sharing tools,
cracked or unlicensed software, personal VPN or proxy tools, and remote-access
tools not provided by IT.

## Browser extensions
Browser extensions follow the same rules as other software. Only extensions on
the approved list may be added.

## Removal
IT may remove software that is prohibited, unlicensed or no longer supported.
Employees are notified before removal unless there is an urgent security risk.

## Applicability
This policy applies to all employees. It replaces v1 in full.
