# How to Use the Company Password Manager

Every employee has a licence for the company password manager. Use it to
store every work password you cannot sign in to with single sign-on. The
rules that passwords must meet are set out in the Password Rules policy; this
page only explains how to use the tool.

## Getting started
1. Install the password manager from the self-service software catalogue.
2. Install the browser extension when prompted.
3. Open the app and sign in with single sign-on.
4. Create your master password. This is the one password you must remember.
   It cannot be recovered by IT, so choose a passphrase you will not forget.

## Saving a password
When you sign in to a website, the browser extension offers to save the
login. You can also add an entry by hand with *New item*.

## Generating passwords
Use the built-in generator when you create or change a password for a work
system. The generator's default settings already follow the Password Rules
policy, so there is no need to change them.

## Sharing with your team
Do not send passwords by email or chat. If a team needs a shared login, ask
your manager to request a shared folder through the IT service portal. Items
in a shared folder can be used by everyone in the folder and are removed
automatically when someone leaves the team.

## Personal passwords
You may keep personal passwords in a separate personal vault. The company
cannot see its contents. When you leave, you can export your personal vault
before your account is closed.

## Forgotten master password
Contact the IT service desk. IT can reset your account, but the items in your
vault will be lost. You will then need to reset the passwords for the systems
you stored.

## Good habits
- Lock the password manager when you step away.
- Use a different password for every system.
- Run the *Security check* page from time to time to find weak or reused
  passwords.
