# How to Get Access to Code Repositories

All company source code lives in the GitHub Enterprise organisation. You sign
in with single sign-on, so you do not need a separate GitHub password.

1. Sign in to GitHub Enterprise with your company account.
2. In the IT service portal, open **Engineering > Repository access** and
   choose the team whose repositories you need.
3. Your team lead approves the request. Access is granted to the whole team,
   not to single repositories.
4. Add an SSH key or set up the GitHub CLI on your laptop so you can clone.

Write access to production infrastructure repositories needs a second
approval from the Platform team. If a repository you expect is missing,
check that your request named the right team before raising a new ticket.
